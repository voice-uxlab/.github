**Voice UX Lab**은 음성으로 대화하는 AI를 직접 만들고, 화면과 텍스트만으로는 알기 어려운 사용 경험을 탐구하는 스터디 팀입니다.

## 대표 프로젝트 · Ten Minutes

**말로 고민을 꺼내고, 직접 뽑은 카드의 해석을 음성으로 듣는 AI 타로 프로젝트.** 타로를 정답을 맞히는 도구가 아니라, 다른 관점에서 고민을 돌아보는 대화의 계기로 사용합니다. 현재 프로토타입을 개발 중입니다.

1. **이야기하기** · 지금 마음에 걸리는 일을 말로 꺼냅니다.
2. **카드 고르기** · 화면에서 직접 타로 카드를 선택합니다.
3. **해석 듣기** · 카드 해석을 음성으로 듣고, 이어서 궁금한 점을 묻습니다.

## 우리가 살펴보는 것

- **대화의 타이밍** · 응답까지의 지연, 말이 겹쳤을 때 끼어들기, 자연스럽게 다음 차례로 넘어가는 방법
- **목소리와 말투** · 같은 내용이라도 말투와 속도에 따라 대화가 어떻게 다르게 느껴지는지
- **음성과 화면의 역할** · 고민은 목소리로 이야기하고, 카드는 손으로 고르는 이유
